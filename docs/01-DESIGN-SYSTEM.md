# Design system

## Colors (single source)
| Token | Hex | Use |
|---|---|---|
| white | #FFFFFF | Page background everywhere |
| blue | #0050FF | Signature. Heading accents, bands, links |
| coral | #FF6B57 | Primary CTAs. Ink text on top |
| yellow | #FFD84D | Tiny pops, stars. Ink text on top |
| sky-mist | #E6EEFF | Cards, strips |
| blush | #FFE6EA | Tints |
| mint | #DDF7EC | Tints, success chips |
| ink | #0B1220 | Text. Body at 72% |

White text on blue. Ink text on coral, yellow, and tints. Check WCAG AA on every pair.
No cream, forest, gold, or glassmorphism tokens.

## Fonts (next/font)
- Bricolage Grotesque 500/600/700: headings, numbers
- Instrument Serif italic: one accent word per headline via <Accent>
- DM Sans 400/500/600: body and UI
Never weight 800/900. Never wide or extended stretch.

## Voice
Founder talking to a friend. Short, specific. Headlines under 10 words.
No em-dashes (use a period, comma, colon, or hyphen).
Banned words: unlock (except code identifiers), elevate, seamless, revolutionize,
leverage, empower, journey, glow-up, game-changer, clinical-level, diagnostic.
Logo is an SVG file.
